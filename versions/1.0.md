# 1.0 — V1 contract complete, hardened, stable

Release checklist. The V1 MVP acceptance criteria in [V1.md](../V1.md) are
the gate; this file tracks them plus the hardening pass (M6).

**Theme:** everything V1.md promises works on real devices, survives abuse,
and ships as `latest`.

## Remaining

### V1 MVP acceptance (both platforms, real devices)

- [ ] Request/check camera and microphone permission.
- [ ] List available camera devices.
- [ ] Render live preview; switch front/back cameras.
- [ ] Capture a photo → local file path.
- [ ] Start/stop video recording → local file path.
- [ ] Zoom, torch, focus-at-point where supported.
- [ ] Survive mount/unmount and background/foreground without crashing.

### Hardening (M6)

- [ ] Rapid mount/unmount stress pass.
- [ ] Permission revoked mid-session → `error` event, no crash.
- [ ] Camera-in-use / interruption handling (calls, other apps).
- [ ] Background/foreground during preview and during recording.

### Release mechanics

- [ ] Native upload story (or documented `includeBase64` guidance) settled —
      JS still can't read temp-file paths.
- [ ] CHANGELOG.md complete for the 0.x line; docs reviewed.
- [ ] Publish with dist-tag `latest`; V0.md marked superseded.
