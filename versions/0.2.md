# 0.2 — Android parity + drop the legacy fallback

Release checklist. Requires 0.1 device-proven first ([0.1.md](0.1.md)).

**Theme:** the package works the same on both platforms at module level, and
sheds its pre-release compatibility shims.

## Remaining

### Android module (M3)

- [ ] Kotlin `CameraModule`: permissions, device enumeration,
      `getChimeraCameraNativeVersion`, interim capture — mirror the iOS
      method list so the install check passes.
- [ ] Extend the version-sync test to cover the Kotlin source.
- [ ] Compile-prove in a real Android Lynx host (the M2 equivalent).

### Android `camera-view` (M2/M4 Android halves)

- [ ] Register `camera-view` via `Behavior`/`LynxUI`, `@LynxUIMethod` `ping()`,
      `LynxDetailEvent` `ready` — pass the bridge-spike acceptance criteria.
- [ ] Live preview via `androidx.camera.view.PreviewView`, `active`/`facing`/
      `resizeMode` props matching iOS.

### Cleanup promised for 0.2.0

- [ ] Remove the legacy `capture(options, callback)` fallback and the
      `legacy-capture-only` install status (V0.md commits to removal before
      0.2.0).
- [ ] Decide: coded errors from the adapter instead of soft-degrading when
      individual native methods are missing.
- [ ] `getDefaultCamera` ordering: prefer the plain wide-angle camera over
      dual/triple virtual devices (known debt in ROADMAP.md).
