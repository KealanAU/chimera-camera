# 0.1 — iOS alpha: V0 module surface + `camera-view` spike

Release checklist for the `0.1.x` line. The behavior contract is
[V0.md](../V0.md); milestone status is [ROADMAP.md](../ROADMAP.md); the
day-to-day working list is [TODO.md](../TODO.md). Tick here when a point is
done so each release file reads as its own changelog-in-advance.

**Theme:** an iOS-only alpha a host app (the consuming app) can ship photo capture with
today, plus the de-risking `camera-view` bridge spike.

## Done

- [x] Package foundation: TypeScript layout, public types, build, CI, release
      workflow, install/testing docs (M0).
- [x] Mock adapter (`@kealanau/chimera-camera/mock`) with photo fixtures;
      honors `includeBase64` like the native paths.
- [x] iOS `ChimeraCameraModule.swift`: permission status/request (camera +
      microphone), device enumeration, `getChimeraCameraNativeVersion` (M1).
- [x] Install checks: `getCameraInstallStatus(+Async)`,
      `assertCameraInstalled(+Async)`, version-sync test across package.json /
      JS / Swift.
- [x] `capturePhoto()` via the system camera UI; `pickPhoto()` via the system
      photo-library picker.
- [x] V0 debt cleared (2026-07-10): captures write a real JPEG temp file
      (`base64` opt-in via `includeBase64`), `maxDimension` downscale cap,
      `flash` mapped, in-flight/presentation hang guards, cold-start presenter
      race fixed, permission callbacks on main.
- [x] iOS `camera-view`: live `AVCaptureVideoPreviewLayer` preview,
      `active`/`facing`/`resizeMode` props, `ready`/`error` events, `ping()`,
      view-session `capturePhoto()` to a temp file (M4/M5 iOS halves).
- [x] JS view surface: `CAMERA_VIEW_TAG`, `createCameraViewHandle`,
      `invokeCameraViewMethod`, tested against a fake SelectorQuery bridge.
- [x] Both native sources compile clean in a real Lynx host (ExampleHost dev
      shell, Xcode 26, Lynx 3.9.0, simulator SDK).
