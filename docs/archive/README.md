# Archived docs

Historical planning specs, kept for reference. They are **not** the living
source of truth:

- Project status, tasks, and release gates live in [ROADMAP.md](../../ROADMAP.md).
- The normalized cross-platform native contract lives in
  [docs/native-contract.md](../native-contract.md).

Contents:

- `V0.md` — the original module-level surface spec. The combined `CameraAdapter`
  it describes is deprecated (see the banner in the file); superseded by the
  `CameraModuleClient` / `CameraViewHandle` split.
- `V1.md` — the original target `camera-view` contract. Its runtime contract is
  now maintained in `docs/native-contract.md`.
